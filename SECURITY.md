# Security policy

This repository is a collection of **legacy Minecraft Skript examples**, not a security-audited or supported production distribution.

## Important warnings

Scripts involving player bans, purchases, account permissions, privileged console commands, or economy balances can cause serious unintended effects when installed unchanged. Use an isolated test server, back up data, and review player input and permission checks.

## Reporting a vulnerability

Please **do not publish exploit instructions, player information, credentials, or private server details in a public GitHub issue**. Contact the repository owner through their GitHub profile to arrange private disclosure, or use GitHub's private vulnerability reporting if the repository offers it.

Include affected file(s), environment, impact, and a safe reproduction outline. There is no promised security response SLA or currently verified support-version matrix.
